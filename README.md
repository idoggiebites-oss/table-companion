# Table Companion (V1)

**Deprecated.** This app has been superseded by
**[table-companion-v2](https://github.com/idoggiebites-oss/table-companion-v2)**,
which serves the same table at the same address.

It is kept, not deleted. V1 is the port's reference for everything V2 left
thin — V2's `PORT.md` accounts for every module here as ported, absorbed, or
deliberately not ported, and the last of those is a list of things whose
reasoning still only exists in this repository.

## If V2 has to be rolled back

`v1-final` is the tag to deploy from, and V2's `ROLLBACK.md` is the procedure.
This repository stays deployable for the whole cutover window.

## Fixes only

No new features. Anything found here is either fixed in V2 or written down in
V2's `PORT.md` so the reasoning is not lost when this stops being deployed.
